# ✂️ BarberFlow - Sistema de Gestão e Agendamento para Barbearias (SaaS)

O **BarberFlow** é uma plataforma completa desenvolvida em **Django** para simplificar o fluxo de agendamentos e a gestão de barbearias. O sistema permite que clientes agendem horários de forma rápida e dá aos barbeiros controle total sobre sua agenda e finanças. Projeto desenvolvido inicialmente para fins acadêmicos, com arquitetura preparada para comercialização no modelo SaaS (Software as a Service).

---

## 🚀 Funcionalidades

### 👤 Área do Cliente
- **Agendamento Online:** Escolha de serviço, profissional, data e horário disponível.
- **Histórico de Agendamentos:** Visualização de agendamentos passados e futuros.
- **Perfil do Cliente:** Cadastro e atualização de dados pessoais.

### 💈 Área Administrativa / Barbeiro
- **Painel de Controle (Dashboard):** Visão geral do fluxo de atendimento diário e semanal.
- **Gestão de Serviços:** Cadastro de cortes, barba, tratamentos, preços e duração.
- **Gestão de Profissionais:** Cadastro de barbeiros e definição de horários de trabalho.
- **Gestão de Clientes:** Listagem e histórico completo de atendimento.

---

## 🛠️ Tecnologias Utilizadas

- **Backend:** Python 3, Django
- **Banco de Dados:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Autenticação:** Django Authentication System
